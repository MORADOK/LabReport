# การอัปเดตระบบหลังแก้บั๊ก

## ก่อนเปิดบริการ

1. ติดตั้ง dependencies ตาม requirements.txt ใน environment ของบริการ
2. ตั้ง DASHBOARD_PASSWORD เป็นรหัสผ่านเฉพาะผู้ดูแลผ่าน environment หรือ .env (ห้าม commit รหัสผ่าน)
3. สำรองฐานข้อมูล แล้วรัน `python -m src.db_handler` ด้วยบัญชีผู้ดูแลฐานข้อมูล Supabase
4. Restart LINE bot และ Streamlit หลัง migration สำเร็จ

Migration เพิ่มคอลัมน์ `diagnostics` JSONB และแก้ policy ชื่อ `Service role full access`
ให้จำกัด `TO service_role` แม้ตารางเปิด RLS อยู่แล้ว ต้องมี role นี้ในฐานข้อมูล
ไม่ลบข้อมูลเก่าและไม่เปลี่ยน policy อื่น หาก migration ล้มเหลว transaction จะ rollback
ควรตรวจ policy อื่นและ grants ตามสภาพแวดล้อมจริงด้วย

การ import โมดูลจะไม่สร้างหรือแก้ schema อีกต่อไป การส่งผลตรวจจะบันทึกไม่สำเร็จ
หากยังไม่รัน migration; ห้ามเปิด bot รุ่นใหม่ก่อนอัปเดตฐานข้อมูล

## พฤติกรรมที่เปลี่ยน

- ต้องถ่ายแผ่นตรวจพร้อมตารางสีผู้ผลิตที่ตรงกับชุดตรวจ เพื่อหลีกเลี่ยงตาราง RGB เดิมที่ขัดกัน
- ค่าที่หายไป ไม่ชัดเจน หรือชนิด Blood กำกวม จะไม่ถูกแทนด้วย negative
- บันทึกผลเฉพาะเมื่อค่าครบและตำแหน่งแถบทั้ง 11 ผ่านการตรวจรูปแบบและไม่ทับซ้อนกัน
- RGB มาจาก median ของพิกเซล JPEG ที่ส่งให้โมเดลจริง ตำแหน่ง ROI ยังเป็นการระบุโดย AI
- เลิกแสดง confidence 85% ที่สร้างขึ้นเมื่อไม่มีหลักฐาน และไม่เชื่อคะแนนที่ AI รายงานเอง
- similarity เป็นระยะห่างสีแบบประมาณการ ไม่ใช่ความแม่นยำทางคลินิก; BLO/ASC/SG ระงับคะแนนเพราะ reference ขัดกัน
- สรุปผลสร้างจากค่าที่ validate แล้ว รายงานคงค่าจริง ไม่รวมเป็นช่วงจนระดับผลเปลี่ยน
- ภาพมืด สว่าง ความละเอียดต่ำ หรือไม่มีรายละเอียดจะถูกขอให้ถ่ายใหม่ เกณฑ์เป็น heuristic
- Dashboard ต้องเข้าสู่ระบบด้วยรหัสผ่านผู้ดูแล ข้อมูล RGB ดูได้ในส่วนตรวจสอบย้อนหลัง
- รองรับ clinical_bullets เก่าที่ถูก encode JSON ซ้ำ และข้อมูลใหม่ encode ครั้งเดียว

## การทดสอบ

รัน `python -B -m unittest test_bot_accuracy test_confidence_score test_workflow -v`

ชุดทดสอบใช้ภาพสังเคราะห์และ mock LINE, AI และฐานข้อมูล ไม่ส่งข้อความ ไม่เรียก AI
และไม่เชื่อมต่อฐานข้อมูลจริง การทดสอบนี้ไม่รับรองความแม่นยำการอ่านภาพจริง
ก่อนใช้งานจริงยังต้องทดสอบภาพแผ่นตรวจที่มี ground truth รวมถึงหน้าจอและ PDF ใน environment ที่ติดตั้ง dependencies ครบ

Migration ยังไม่ได้รันกับฐานข้อมูลจริงจากงานแก้โค้ดครั้งนี้ และยังไม่มีการ deploy หรือ push
